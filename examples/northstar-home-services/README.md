# Northstar Home Services: a synthetic engagement

Everything in this folder is made up. Northstar Home Services does not exist, its people are invented, and every number was chosen to make the example readable, not to describe any existing company. It is here so you can see what a populated client folder and the finished deliverables look like before you run your first engagement.

The shape mirrors `context/clients/README.md`.

```text
engagement.md                       Scope, units, calendar, gates, contacts, workspace
recaps/2026-03-04-current-state.md  A current state recap, with the extraction block
reports/future-state-dispatch.md    One future state recommendation, for one workflow
reports/quantification-of-impact.md The gate 1 numbers, from the (imaginary) workspace
reports/innovation-report.md        The close-out report, after the demo
```

The consultant in this example is "Avery Lane, Lane Operations", solo, expert in HubSpot, Workiz, Zapier and Make, serving home services companies in the United States. That profile is the example `consultant.md`; it is not anyone's.
