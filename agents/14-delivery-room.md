# Delivery Room

A group chat, not a Bot: the Chief of Staff, the Delivery Lead and every specialist in one room, so a recap, a map, a build request and a changelog entry can be handed over without you relaying them.

| | |
|---|---|
| Members | Chief of Staff, Delivery Lead, Recap Writer, Trainer, Current State Mapper, Tech Stack Researcher, Product Changes Researcher, Process Architect, Impact Analyst, Build Specialist, Data Cleaner (when created), Change Manager |
| Rule | Short pointers only. The work lives in the client's Puzzle workspace and in files. |

Create it in Grok Bot as a group chat with these members, or let the [setup prompt](../setup-prompt.md) do it.
